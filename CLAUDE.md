# Instructions for Claude

## Commits and pull requests

- End commit messages with an `Assisted-by:` trailer, not `Co-Authored-By:`,
  e.g. `Assisted-by: Claude <noreply@anthropic.com>`.
- Do not include links to Claude sessions (e.g. `Claude-Session:` trailers or
  `claude.ai/code/session_...` URLs) in commit messages, pull request
  descriptions, comments or any other content pushed to GitHub.
