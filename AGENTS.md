# Instructions for AI coding agents

## Commits and pull requests

- End commit messages with a `Co-Authored-By:` trailer naming the AI model
  and version that did the work, e.g.
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Do not include links to agent sessions (e.g. `Claude-Session:` trailers or
  `claude.ai/code/session_...` URLs) in commit messages, pull request
  descriptions, comments or any other content pushed to GitHub.
